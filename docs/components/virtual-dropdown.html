Virtual Dropdown

Virtualised searchable dropdown for large datasets. Only the visible rows are rendered to the DOM — 10,000+ items scroll smoothly. Supports single and multi-select modes.

Customising the selection summary

When multiSelect is on, the trigger shows a summary like "3 items selected" once something is picked. selectedLabel replaces that summary — it's a property in the same config object you already pass to new VirtualDropdown({ ... }), sitting right next to container, options, multiSelect, etc.

It's a plain JavaScript function, not a template string — there's no "N Elemente ausgewählt" placeholder text to type in. The component calls your function with the current selection count every time it changes, and shows whatever string comes back, unmodified:

Options

OptionTypeDefaultDescription
containerstring | Element—CSS selector or DOM element to mount into.
options{ value, label }[][]Full option list — can be thousands of items.
placeholderstring'Select…'Text shown when nothing is selected.
searchablebooleanfalseShow a search input at the top of the list.
multiSelectbooleanfalseAllow selecting multiple items.
renderLimitnumber20Number of items rendered per virtual scroll window.
itemHeightnumber40Row height in px — must match CSS to calculate scroll positions correctly.
onSelectfunction—Called with (selectedValues: Array<string|number>) on any selection change.
selectedLabelfunctionEnglish "N items selected"(count: number) => string — the trigger's summary text when multiSelect is on and at least one item is selected. The component doesn't pluralise for you; return whatever's grammatically correct for count in your language.

API

MethodDescription
getValue()Returns the current selection as Array<string|number>.
setValue(values)Programmatically set the selection. Ignores values not in the options list.
clearSelection()Clears all selected values and resets the trigger label.
