Layout & Grid

Two layout systems: a flexbox-based .row/.column grid, and a CSS Grid-based .grid/.cell grid. Both stack on mobile automatically.

Flexbox or Grid?

Use .row / .column
  • A single row where content should size the columns
  • Toolbars, button groups, form rows
  • Proportional widths via grow-2…grow-6
Use .grid / .cell
  • Card or product grids with an unknown item count
  • Layouts that should reflow without a breakpoint
  • Content that must align across multiple rows
  • An explicit column count, e.g. "8 of 12" via .cols-12 + .span-8

Rule of thumb: content sizes the layout → flexbox. Layout sizes the content → grid. Both systems mix freely — a .cell can hold a .row and vice versa — and .row/.column is not deprecated.

CSS Grid

A CSS Grid-based layout system using .grid and .cell. Reflows automatically without a breakpoint by default, or use .cols-1 through .cols-12 for a fixed number of tracks. Add .span-2 through .span-12 (or .span-full) on a .cell for an explicit column layout. Stacks to a single column on mobile.
